# Các tính năng tìm kiếm và lọc
## Inventory
- Tìm kiếm theo: 
  + Tên sản phẩm: `?search=keyword` (tìm trong `product_variant__product__name`)
  + Mã SKU: `?search=keyword` (tìm trong `product_variant__sku`)
  + Tên cửa hàng: `?search=keyword` (tìm trong `store__name`)
- Lọc theo: 
  + Cửa hàng: `?store=1`
  + Biến thể sản phẩm: `?product_variant=1`
- Sắp xếp theo: 
  + Số lượng: `?ordering=quantity` hoặc `?ordering=-quantity`
  + Thời gian cập nhật: `?ordering=last_updated` hoặc `?ordering=-last_updated`
  + Thời gian tạo: `?ordering=created_at` hoặc `?ordering=-created_at`
- Phân trang: Mặc định 10 items/trang
- API list_all: Lấy tất cả tồn kho không phân trang

# Quyền truy cập
## Content
- Cho phép xem danh sách và chi tiết mà không cần đăng nhập (AllowAny)
- Yêu cầu quyền admin cho các thao tác thêm/sửa/xóa (IsAdminUser)

## Reports
- Cho phép user đã đăng nhập xem báo cáo (IsAuthenticated)
- Yêu cầu quyền admin cho các thao tác thay đổi dữ liệu (IsAdminUser)

## Warranty
- Cho phép user đã đăng nhập xem danh sách và chi tiết bảo hành (IsAuthenticated)
- Yêu cầu quyền admin cho các thao tác thêm/sửa/xóa (IsAdminUser)

# Các tính năng tìm kiếm và lọc
## Orders
- Tìm kiếm theo: 
  + Mã đơn hàng: `?search=keyword` (tìm trong `order_number`)
  + Tên khách hàng: `?customer_first_name=keyword` (tìm trong `customer__first_name`)
- Lọc theo: 
  + Khách hàng: `?customer=1`
  + Trạng thái: `?status=pending`
  + Phương thức thanh toán: `?payment_method=cash`
  + Cửa hàng: `?store=1`
- Sắp xếp theo: 
  + Mã đơn hàng: `?ordering=order_number` hoặc `?ordering=-order_number`
  + Thời gian tạo: `?ordering=created_at` hoặc `?ordering=-created_at`
- Phân trang: Mặc định 10 items/trang
- API list_all: Lấy tất cả đơn hàng không phân trang

## OrderDetails
- Tìm kiếm theo: 
  + Mã đơn hàng: `?search=keyword` (tìm trong `order__order_number`)
  + Mã SKU: `?search=keyword` (tìm trong `product_variant__sku`)
- Lọc theo: 
  + Đơn hàng: `?order=1`
  + Biến thể sản phẩm: `?product_variant=1`
- Sắp xếp theo: 
  + Thời gian tạo: `?ordering=created_at` hoặc `?ordering=-created_at`
- Phân trang: Mặc định 10 items/trang
- API list_all: Lấy tất cả chi tiết đơn hàng không phân trang

# Quyền truy cập
## Orders
- Cho phép user đã đăng nhập xem danh sách và chi tiết đơn hàng (IsAuthenticated)
- Yêu cầu quyền admin cho các thao tác thêm/sửa/xóa (IsAdminUser)
- Người dùng thông thường chỉ có thể xem đơn hàng của cửa hàng họ thuộc về
- Superuser có thể xem và quản lý tất cả đơn hàng

## OrderDetails
- Cho phép user đã đăng nhập xem danh sách và chi tiết chi tiết đơn hàng (IsAuthenticated)
- Yêu cầu quyền admin cho các thao tác thêm/sửa/xóa (IsAdminUser)
- Người dùng thông thường chỉ có thể xem chi tiết đơn hàng của cửa hàng họ thuộc về
- Superuser có thể xem và quản lý tất cả chi tiết đơn hàng
