# PRODUCT API

## 1. GET /api/products/products/
- Lấy danh sách sản phẩm
- Query params:
  - category: ID danh mục
  - brand: ID thương hiệu
  - min_price: Giá tối thiểu
  - max_price: Giá tối đa
  - search: Tìm kiếm theo tên/mô tả
  - featured: true/false (sản phẩm nổi bật)
  - is_active: true/false (trạng thái hoạt động của sản phẩm)
- Response:
```json
[
  {
    "id": 1,
    "name": "Tên sản phẩm",
    "description": "Mô tả sản phẩm",
    "category": 1,
    "category_detail": {
      "id": 1,
      "name": "Tên danh mục"
    },
    "brand": 1,
    "brand_detail": {
      "id": 1,
      "name": "Tên thương hiệu"
    },
    "base_price": "1000000.00",
    "warranty_period": 12,
    "slug": "ten-san-pham",
    "meta_title": "Meta title",
    "meta_description": "Meta description",
    "is_featured": true,
    "is_active": true,
    "default_variant": 1,
    "variants": [],
    "images": []
  }
]
```

## 2. POST /api/products/products/
- Tạo sản phẩm mới
- Body:
```json
{
  "name": "Tên sản phẩm",
  "description": "Mô tả sản phẩm",
  "category": 1,
  "brand": 1,
  "base_price": "1000000.00",
  "warranty_period": 12,
  "meta_title": "Meta title",
  "meta_description": "Meta description",
  "is_featured": true,
  "is_active": true,
  "attribute_value_groups": [[1, 2], [3, 4]], // Các nhóm giá trị thuộc tính
  "images": [file1, file2], // Files
  "primary_image_index": 0 // Index của ảnh chính
}
```

## 3. PUT /api/products/products/{id}/
- Cập nhật sản phẩm
- Body: Tương tự POST

## 4. DELETE /api/products/products/{id}/
- Xóa mềm sản phẩm

## 5. GET /api/products/products/{id}/
- Lấy chi tiết sản phẩm
- Response: Tương tự GET list nhưng có thêm thông tin chi tiết

## 6. POST /api/products/products/{id}/bulk_update_variants/
- Cập nhật hàng loạt biến thể
- Body:
```json
{
  "variants": [
    {
      "price_adjustment": "100000.00",
      "stock_alert_threshold": 10,
      "barcode": "123456789",
      "is_active": true,
      "attribute_values": [1, 2, 3]
    }
  ]
}
```

## 7. GET /api/products/products/{id}/get_attributes/
- Lấy danh sách thuộc tính của sản phẩm
- Response:
```json
[
  {
    "id": 1,
    "name": "Tên thuộc tính",
    "description": "Mô tả thuộc tính",
    "values": [
      {
        "id": 1,
        "value": "Giá trị thuộc tính"
      }
    ]
  }
]
```

## 8. POST /api/products/products/{id}/set_primary_image/
- Đặt ảnh chính cho sản phẩm
- Body:
```json
{
  "image_id": 1 // ID của ảnh cần đặt làm ảnh chính
}
```
- Response:
```json
{
  "message": "Đã đặt ảnh chính thành công",
  "image": {
    "id": 1,
    "product": 1,
    "image": "path/to/image.png",
    "is_primary": true
  }
}
```

# PRODUCT VARIANT API

## 1. GET /api/products/variants/
- Lấy danh sách biến thể
- Query params:
  - search: Tìm kiếm theo tên sản phẩm/giá trị thuộc tính
  - attr_values: Danh sách giá trị thuộc tính
  - attr_type: Loại thuộc tính
  - sort_by: Sắp xếp theo tên sản phẩm (product_name/-product_name)
  - attr_value: Lọc theo giá trị thuộc tính
- Response:
```json
[
  {
    "id": 1,
    "product": 1,
    "product_name": "Tên sản phẩm",
    "sku": "SKU123",
    "price_adjustment": "100000.00",
    "stock_alert_threshold": 10,
    "barcode": "123456789",
    "is_active": true,
    "attribute_values": [1, 2, 3],
    "attribute_values_detail": [
      {
        "id": 1,
        "value": "Giá trị",
        "attribute_type": {
          "id": 1,
          "name": "Tên thuộc tính"
        }
      }
    ]
  }
]
```

## 2. POST /api/products/variants/
- Tạo biến thể mới
- Body:
```json
{
  "product_id": 1,
  "price_adjustment": "100000.00",
  "stock_alert_threshold": 10,
  "barcode": "123456789",
  "is_active": true,
  "attribute_values": [1, 2, 3]
}
```

## 3. PUT /api/products/variants/{id}/
- Cập nhật biến thể
- Body: Tương tự POST

## 4. DELETE /api/products/variants/{id}/
- Xóa biến thể

## 5. GET /api/products/variants/{id}/
- Lấy chi tiết biến thể
- Response: Tương tự GET list

## 6. POST /api/products/variants/{id}/upload_images/
- Upload nhiều ảnh cho biến thể
- Body (multipart/form-data):
  - images: Danh sách file ảnh
  - alt_texts: Danh sách alt text tương ứng (optional)
- Response:
```json
[
  {
    "id": 1,
    "variant": 1,
    "image": "path/to/image.jpg",
    "alt_text": "Mô tả ảnh"
  }
]
```

## 7. DELETE /api/products/variants/{id}/delete_image/
- Xóa một ảnh của biến thể
- Body:
```json
{
  "image_id": 1
}
```

# VARIANT IMAGE API

## 1. GET /api/products/variant-images/
- Lấy danh sách ảnh biến thể
- Query params:
  - variant: ID biến thể
  - product: ID sản phẩm (lấy tất cả ảnh biến thể của sản phẩm)
- Response:
```json
[
  {
    "id": 1,
    "variant": 1,
    "image": "path/to/image.png",
    "alt_text": "Mô tả ảnh"
  }
]
```

## 2. POST /api/products/variant-images/
- Tạo ảnh biến thể mới
- Body (multipart/form-data):
  - variant: ID biến thể
  - image: File ảnh
  - alt_text: Mô tả ảnh (optional)

## 3. PUT /api/products/variant-images/{id}/
- Cập nhật ảnh biến thể
- Body:
```json
{
  "alt_text": "Mô tả ảnh mới"
}
```

## 4. DELETE /api/products/variant-images/{id}/
- Xóa ảnh biến thể
