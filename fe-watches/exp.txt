
- `store`: Filter by store ID (e.g., `?store=1`)
- `position`: Filter by position (e.g., `?position=Store Manager`)
- `employee_code`: Filter by employee code (e.g., `?employee_code=EMP001`)
- `search`: Search in username, email, first_name, last_name, phone

## Query Parameters

### Store List
- `name`: Filter by store name
- `address`: Filter by store address
- `is_active`: Filter by active status
- `search`: Search in name, address, phone, email
- `ordering`: Order by name, created_at

### Employee List
- `store`: Filter by store ID
- `position`: Filter by position
- `employee_code`: Filter by employee code
- `search`: Search in username, email, first_name, last_name, phone
- `ordering`: Order by created_at

### Store Inventory List
- `store`: Filter by store ID
- `product_variant`: Filter by product variant ID
- `quantity`: Filter by quantity
- `ordering`: Order by last_updated, created_at

## Authentication
All endpoints require authentication using JWT token:
```http
Authorization: Bearer <your_jwt_token>
```

## Permissions
- Superuser: Full access to all endpoints
- Store Manager: Full access to their store's data
- Store Staff: Read-only access to their store's data
