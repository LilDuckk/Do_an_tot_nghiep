2. Product Variants API:
Base URL: localhost:8000/api/products/variants/

GET:
[
    {
        "id": 1,
        "product": 1,
        "sku": "PRODUCT-NAME-RED-SMALL-1",
        "price_adjustment": "10.00",
        "stock_alert_threshold": 5,
        "barcode": "123456789",
        "is_active": true,
        "attribute_values": [1, 3],
        "created_at": "2024-03-20T10:00:00Z",
        "updated_at": "2024-03-20T10:00:00Z"
    }
]

// Lọc biến thể theo thuộc tính:
GET localhost:8000/api/products/variants/?attribute_values=1,2,3
// Lọc các biến thể có chứa các thuộc tính có ID là 1, 2, 3

GET localhost:8000/api/products/variants/?product=1&attribute_values=1,2
// Lọc các biến thể của sản phẩm có ID=1 và có chứa các thuộc tính có ID là 1, 2

GET localhost:8000/api/products/variants/?attribute_type=1&attribute_value=2
// Lọc các biến thể có thuộc tính loại 1 (ví dụ: màu sắc) và giá trị thuộc tính là 2 (ví dụ: màu xanh)

GET localhost:8000/api/products/variants/?min_price=100&max_price=1000&attribute_values=1,2
// Lọc các biến thể có giá từ 100-1000 và có chứa các thuộc tính có ID là 1, 2

GET localhost:8000/api/products/variants/?is_active=true&attribute_values=1,2,3
// Lọc các biến thể đang active và có chứa các thuộc tính có ID là 1, 2, 3

// Kết hợp nhiều điều kiện:
GET localhost:8000/api/products/variants/?product=1&attribute_values=1,2&min_price=100&max_price=1000&is_active=true
// Lọc các biến thể của sản phẩm có ID=1, có giá từ 100-1000, đang active và có chứa các thuộc tính có ID là 1, 2

POST:
{
    "product_id": 1,
    "price_adjustment": "10.00",
    "stock_alert_threshold": 5,
    "barcode": "123456789",
    "is_active": true,
    "attribute_values": [1, 3]
}

PUT:
{
    "price_adjustment": "15.00",
    "stock_alert_threshold": 10,
    "barcode": "987654321",
    "is_active": true,
    "attribute_values": [1, 3]
}

4. Attribute Values API:
Base URL: localhost:8000/api/products/attribute-values/

GET:
[
    {
        "id": 1,
        "attribute_type": 1,
        "value": "Đỏ",
        "price_adjustments": [
            {
                "id": 1,
                "product": 1,
                "price_adjustment": "300.00"
            }
        ],
        "created_at": "2024-03-20T10:00:00Z",
        "updated_at": "2024-03-20T10:00:00Z"
    }
]

POST:
{
    "attribute_type": 1,
    "value": "Đỏ"
}

DELETE:
// Khi xóa một thuộc tính, hệ thống sẽ:
// 1. Tìm tất cả các biến thể có chứa thuộc tính này
// 2. Xóa các biến thể đó
// 3. Xóa các price adjustments liên quan
// 4. Xóa thuộc tính

DELETE localhost:8000/api/products/attribute-values/1/
Response:
{
    "message": "Attribute value deleted successfully",
    "deleted_variants": [
        {
            "id": 1,
            "sku": "PRODUCT-NAME-RED-SMALL-1",
            "product": 1
        },
        {
            "id": 2,
            "sku": "PRODUCT-NAME-RED-LARGE-2",
            "product": 1
        }
    ],
    "deleted_price_adjustments": [
        {
            "id": 1,
            "product": 1,
            "price_adjustment": "300.00"
        }
    ]
}

// Nếu muốn xóa thuộc tính mà không xóa các biến thể:
DELETE localhost:8000/api/products/attribute-values/1/?keep_variants=true
Response:
{
    "message": "Attribute value deleted successfully. Variants were kept but attribute value was removed from them.",
    "affected_variants": [
        {
            "id": 1,
            "sku": "PRODUCT-NAME-RED-SMALL-1",
            "product": 1,
            "new_sku": "PRODUCT-NAME-SMALL-1"  // SKU được cập nhật sau khi xóa thuộc tính
        },
        {
            "id": 2,
            "sku": "PRODUCT-NAME-RED-LARGE-2",
            "product": 1,
            "new_sku": "PRODUCT-NAME-LARGE-2"
        }
    ]
}

6. Additional Product Endpoints:

GET Featured Products:
localhost:8000/api/products/products/featured/
[
    {
        "id": 1,
        "name": "Featured Product",
        ...
    }
]

Bulk Update Variants:
POST localhost:8000/api/products/{id}/bulk_update_variants/
{
    "variants": [
        {
            "sku": "PRODUCT-NAME-RED-SMALL-1",
            "price_adjustment": "15.00",
            "stock_alert_threshold": 5,
            "barcode": "123456789",
            "is_active": true,
            "attribute_values": [1, 3]
        }
    ]
}

Filter Products:
GET localhost:8000/api/products/products/?category=1&brand=2&min_price=100&max_price=1000&search=watch&featured=true&active=true
[
    {
        "id": 1,
        "name": "Filtered Product",
        ...
    }
]

Form fields:
1. name: "Casio"
2. base_price: "1000.00"
3. description: "Đồng hồ Casio"
4. images[0]: [file1]
