- Sản phẩm:
	Bảng Danh mục sản phẩm (ProductCategories)
		+ ID danh mục (loại) sản phẩm: CategoryID 
		+ Tên danh mục (loại) sản phẩm: CategoryName 
		+ Ghi chú danh mục (loại) sản phẩm: CategoryDescription 
		+ ID danh mục cha: ParentCategoryID 
	Bảng Hãng (Brands)
		+ ID hãng: BrandID 
		+ Tên hãng: BrandName 
		+ Mô tả hãng: BrandDescription 
	Bảng Sản phẩm (Products)
		+ ID sản phẩm: ProductID 
		+ Tên sản phẩm: ProductName 
		+ Mô tả sản phẩm: ProductDescription 
		+ ID danh mục sản phẩm: CategoryID 
		+ ID hãng: BrandID 
		+ Giá gốc: BasePrice 
	Bảng Thuộc tính (Attributes)
		+ ID thuộc tính: AttributeID 
		+ Tên thuộc tính: AttributeName
		+ Mô tả thuộc tính: AttributeDescription 
	Bảng Thuộc tính của danh mục (CategoryAttributes)
		+ ID danh mục sản phẩm: CategoryID 
		+ ID thuộc tính: AttributeID 
		+ Yêu cầu: IsRequired 
		+ Ảnh hưởng đến giá: AffectsPrice 
		+ Thứ tự hiển thị: DisplayOrder 
	Bảng Giá trị thuộc tính (AttributeValues)
		+ ID giá trị thuộc tính: AttributeValueID 
		+ ID thuộc tính: AttributeID 
		+ Giá trị thuộc tính: Value 
	Bảng Biến thể sản phẩm (ProductVariants)
		+ ID biến thể: VariantID 
		+ ID sản phẩm: ProductID 
		+ Mã SKU: SKUCode 
		+ Điều chỉnh giá: PriceAdjustment 
		+ Số lượng tồn kho: Stock 
		+ Trạng thái kích hoạt: IsActive 
	Bảng Thuộc tính của biến thể sản phẩm (ProductVariantAttributes)
		+ ID biến thể: VariantID 
		+ ID giá trị thuộc tính: AttributeValueID
