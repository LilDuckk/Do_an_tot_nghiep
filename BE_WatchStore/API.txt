API Documentation for Watch Store

Base URL: /api/

1. Authentication APIs:
   - POST /auth/login/ - Đăng nhập
   - POST /auth/register/ - Đăng ký
   - POST /auth/refresh/ - Làm mới token

2. Product Category APIs:
   - GET /categories/ - Lấy danh sách danh mục
   - GET /categories/{id}/ - Lấy chi tiết danh mục
   - POST /categories/ - Tạo danh mục mới
   - PUT /categories/{id}/ - Cập nhật danh mục
   - DELETE /categories/{id}/ - Xóa danh mục

3. Brand APIs:
   - GET /brands/ - Lấy danh sách thương hiệu

Query Parameters:
- page: Số trang (mặc định: 1)
- page_size: Số lượng item trên mỗi trang (mặc định: 10)
- ordering: Sắp xếp theo trường (VD: -created_at)
- search: Tìm kiếm theo từ khóa
- filters: Lọc theo các trường

Response Format:
{
    "count": total_items,
    "next": next_page_url,
    "previous": previous_page_url,
    "results": [
        {
            "id": item_id,
            ...item_fields
        }
    ]
}
