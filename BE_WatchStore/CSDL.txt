PHÂN TÍCH CƠ SỞ DỮ LIỆU WATCH STORE

1. TỔNG QUAN
- Đây là một cơ sở dữ liệu cho hệ thống quản lý cửa hàng đồng hồ
- Sử dụng Django Framework với Django ORM
- Hệ thống bao gồm các module chính: Quản lý sản phẩm, Quản lý đơn hàng, Quản lý khách hàng, Quản lý kho, Quản lý nhân viên

2. CHI TIẾT CÁC BẢNG DỮ LIỆU

2.1. Quản lý sản phẩm

a) ProductCategory (Danh mục sản phẩm)
- PK: id (Auto)
- Thuộc tính:
  + name (CharField, max_length=255)
  + description (TextField, null=True)
  + parent (ForeignKey -> ProductCategory, null=True)
  + image_url (URLField, null=True)
  + is_active (BooleanField, default=True)
  + display_order (IntegerField, default=0)
  + is_deleted (BooleanField, default=False)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

b) Brand (Thương hiệu)
- PK: id (Auto)
- Thuộc tính:
  + name (CharField, max_length=255)
  + description (TextField, null=True)
  + logo_url (URLField, null=True)
  + is_active (BooleanField, default=True)
  + display_order (IntegerField, default=0)
  + is_deleted (BooleanField, default=False)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

c) Product (Sản phẩm)
- PK: id (Auto)
- FK:
  + category (ForeignKey -> ProductCategory)
  + brand (ForeignKey -> Brand)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + name (CharField, max_length=255)
  + description (TextField, null=True)
  + base_price (DecimalField, max_digits=10, decimal_places=2)
  + is_active (BooleanField, default=True)
  + is_deleted (BooleanField, default=False)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

d) ProductVariant (Biến thể sản phẩm)
- PK: id (Auto)
- FK:
  + product (ForeignKey -> Product)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + sku_code (CharField, max_length=255, unique=True)
  + price_adjustment (DecimalField, max_digits=10, decimal_places=2)
  + stock (IntegerField, default=0)
  + is_active (BooleanField, default=True)
  + barcode (CharField, max_length=50, null=True)
  + weight (DecimalField, max_digits=10, decimal_places=2, null=True)
  + dimensions (CharField, max_length=50, null=True)
  + is_deleted (BooleanField, default=False)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

e) ProductSpecification (Thông số kỹ thuật)
- PK: id (Auto)
- FK:
  + product (ForeignKey -> Product)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + name (CharField, max_length=100)
  + value (TextField)
  + display_order (IntegerField, default=0)
  + is_deleted (BooleanField, default=False)

2.2. Quản lý đơn hàng

a) Order (Đơn hàng)
- PK: id (Auto)
- FK:
  + customer (ForeignKey -> Customer)
  + store (ForeignKey -> Store)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + order_date (DateTimeField, auto_now_add=True)
  + total_amount (DecimalField, max_digits=10, decimal_places=2)
  + status (CharField, max_length=20, choices=STATUS_CHOICES)
  + payment_method (CharField, max_length=50)
  + shipping_address (TextField)
  + shipping_fee (DecimalField, max_digits=10, decimal_places=2)
  + discount_amount (DecimalField, max_digits=10, decimal_places=2)
  + final_amount (DecimalField, max_digits=10, decimal_places=2)
  + is_deleted (BooleanField, default=False)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

b) OrderDetail (Chi tiết đơn hàng)
- PK: id (Auto)
- FK:
  + order (ForeignKey -> Order)
  + product (ForeignKey -> Product)
- Thuộc tính:
  + quantity (IntegerField)
  + unit_price (DecimalField, max_digits=10, decimal_places=2)

c) Shipment (Vận chuyển)
- PK: id (Auto)
- FK:
  + order (ForeignKey -> Order)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + shipping_method (CharField, max_length=50)
  + tracking_number (CharField, max_length=100, null=True)
  + status (CharField, max_length=50)
  + estimated_delivery_date (DateField)
  + actual_delivery_date (DateField, null=True)
  + is_deleted (BooleanField, default=False)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

2.3. Quản lý khách hàng

a) Customer (Khách hàng)
- PK: id (Auto)
- FK:
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + first_name (CharField, max_length=100)
  + last_name (CharField, max_length=100)
  + email (EmailField, unique=True, null=True)
  + phone (CharField, max_length=15)
  + address (TextField, null=True)
  + created_at (DateTimeField, auto_now_add=True)
  + last_purchase_date (DateTimeField, null=True)
  + total_purchases (IntegerField, default=0)
  + total_spent (DecimalField, max_digits=10, decimal_places=2, default=0)
  + notes (TextField, null=True)
  + customer_type (CharField, max_length=20, null=True)
  + birth_date (DateField, null=True)
  + gender (CharField, max_length=10, null=True)
  + is_deleted (BooleanField, default=False)
  + updated_at (DateTimeField, auto_now=True)

b) ProductWishlist (Danh sách yêu thích)
- PK: id (Auto)
- FK:
  + customer (ForeignKey -> Customer)
  + product (ForeignKey -> Product)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + added_date (DateTimeField, auto_now_add=True)
  + is_deleted (BooleanField, default=False)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)
- UniqueConstraint: ['customer', 'product']

c) ProductReview (Đánh giá sản phẩm)
- PK: id (Auto)
- FK:
  + product (ForeignKey -> Product)
  + customer (ForeignKey -> Customer)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + rating (IntegerField, validators=[MinValueValidator(1), MaxValueValidator(5)])
  + comment (TextField)
  + review_date (DateTimeField, auto_now_add=True)
  + is_approved (BooleanField, default=False)
  + is_deleted (BooleanField, default=False)

2.4. Quản lý kho

a) Store (Cửa hàng)
- PK: id (Auto)
- FK:
  + manager (ForeignKey -> Employee, null=True)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + name (CharField, max_length=255)
  + address (TextField)
  + phone (CharField, max_length=15)
  + store_code (CharField, max_length=50, unique=True)
  + store_type (CharField, max_length=50)
  + is_active (BooleanField, default=True)
  + opening_date (DateField)
  + closing_date (DateField, null=True)
  + is_deleted (BooleanField, default=False)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

b) Inventory (Tồn kho)
- PK: id (Auto)
- FK:
  + store (ForeignKey -> Store)
  + product (ForeignKey -> Product)
- Thuộc tính:
  + quantity_in_stock (IntegerField, default=0)
  + minimum_stock (IntegerField, default=0)
  + maximum_stock (IntegerField)
  + last_restocked_date (DateTimeField, auto_now=True)
- UniqueConstraint: ['store', 'product']

c) StockIn (Nhập kho)
- PK: id (Auto)
- FK:
  + store (ForeignKey -> Store)
  + product (ForeignKey -> Product)
- Thuộc tính:
  + quantity (IntegerField)
  + cost_price (DecimalField, max_digits=10, decimal_places=2)
  + stock_in_date (DateField)
  + supplier_name (CharField, max_length=255)

d) StockOut (Xuất kho)
- PK: id (Auto)
- FK:
  + store (ForeignKey -> Store)
  + product (ForeignKey -> Product)
  + employee (ForeignKey -> Employee)
- Thuộc tính:
  + quantity (IntegerField)
  + sale_price (DecimalField, max_digits=10, decimal_places=2)
  + stock_out_date (DateField)

2.5. Quản lý nhân viên

a) Employee (Nhân viên)
- PK: id (Auto)
- FK:
  + user (OneToOneField -> User)
  + created_by (ForeignKey -> User, null=True)
  + updated_by (ForeignKey -> User, null=True)
- Thuộc tính:
  + first_name (CharField, max_length=100)
  + last_name (CharField, max_length=100)
  + email (EmailField, unique=True)
  + phone (CharField, max_length=15)
  + role (CharField, max_length=50)
  + hire_date (DateField)
  + employee_code (CharField, max_length=50, unique=True)
  + position (CharField, max_length=100)
  + department (CharField, max_length=100)
  + salary (DecimalField, max_digits=10, decimal_places=2)
  + is_active (BooleanField, default=True)
  + is_deleted (BooleanField, default=False)
  + created_at (DateTimeField, auto_now_add=True)
  + updated_at (DateTimeField, auto_now=True)

3. MỐI QUAN HỆ GIỮA CÁC BẢNG

3.1. Quan hệ một-nhiều (One-to-Many)
- ProductCategory -> Product (một danh mục có nhiều sản phẩm)
- Brand -> Product (một thương hiệu có nhiều sản phẩm)
- Product -> ProductVariant (một sản phẩm có nhiều biến thể)
- Product -> ProductSpecification (một sản phẩm có nhiều thông số)
- Customer -> Order (một khách hàng có nhiều đơn hàng)
- Store -> Order (một cửa hàng có nhiều đơn hàng)
- Order -> OrderDetail (một đơn hàng có nhiều chi tiết)
- Product -> OrderDetail (một sản phẩm có trong nhiều chi tiết đơn hàng)
- Store -> Inventory (một cửa hàng có nhiều tồn kho)
- Product -> Inventory (một sản phẩm có trong nhiều tồn kho)
- Store -> StockIn (một cửa hàng có nhiều phiếu nhập)
- Product -> StockIn (một sản phẩm có trong nhiều phiếu nhập)
- Store -> StockOut (một cửa hàng có nhiều phiếu xuất)
- Product -> StockOut (một sản phẩm có trong nhiều phiếu xuất)
- Employee -> StockOut (một nhân viên thực hiện nhiều phiếu xuất)

3.2. Quan hệ nhiều-nhiều (Many-to-Many)
- Customer -> Product (thông qua ProductWishlist)
- Customer -> Product (thông qua ProductReview)

3.3. Quan hệ một-một (One-to-One)
- User -> Employee (một tài khoản ứng với một nhân viên)

4. ĐẶC ĐIỂM NỔI BẬT
- Thiết kế chuẩn hóa và tối ưu
- Hỗ trợ đa ngôn ngữ (verbose_name)
- Theo dõi người tạo/cập nhật và thời gian
- Soft delete (is_deleted flag)
- Tích hợp Django User Authentication
- Quan hệ phức tạp giữa các bảng
- Validation và ràng buộc dữ liệu
- UniqueConstraint cho các trường quan trọng
- ForeignKey với on_delete=CASCADE/SET_NULL phù hợp
