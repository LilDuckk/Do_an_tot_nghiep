# API Endpoints cho Store
## Danh sách API
GET /api/stores/ - Lấy danh sách stores (có phân trang)
GET /api/stores/list_all/ - Lấy tất cả stores (không phân trang)
GET /api/stores/{id}/ - Lấy chi tiết một store
GET /api/stores/{id}/employee_count/ - Lấy số lượng nhân viên của store
POST /api/stores/ - Tạo store mới
PUT /api/stores/{id}/ - Cập nhật store
DELETE /api/stores/{id}/ - Xóa store

# Các tính năng tìm kiếm và lọc
## Store
- Tìm kiếm theo: name, address, phone
- Lọc theo: is_active
- Sắp xếp theo: name, created_at, updated_at
- Phân trang: Mặc định 10 items/trang
- API đếm nhân viên: /api/stores/{id}/employee_count/

## Employee
- Tìm kiếm theo: name, phone, employee_code
- Lọc theo: store, position, is_manager
- Sắp xếp theo: name, hire_date, created_at
- Phân trang: Mặc định 10 items/trang

# Các tính năng tìm kiếm và lọc
## Inventory
- Tìm kiếm theo: 
  + Tên sản phẩm: `?search=keyword` (tìm trong `product_variant__product__name`)
  + Mã SKU: `?search=keyword` (tìm trong `product_variant__sku`)
  + Tên cửa hàng: `?search=keyword` (tìm trong `store__name`)
- Lọc theo: 
  + Cửa hàng: `?store=1`
  + Biến thể sản phẩm: `?product_variant=1`
- Sắp xếp theo: 
  + Số lượng: `?ordering=quantity` hoặc `?ordering=-quantity`
  + Thời gian cập nhật: `?ordering=last_updated` hoặc `?ordering=-last_updated`
  + Thời gian tạo: `?ordering=created_at` hoặc `?ordering=-created_at`
- Phân trang: Mặc định 10 items/trang
- API list_all: Lấy tất cả tồn kho không phân trang
