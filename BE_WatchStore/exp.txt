7. Additional Product Endpoints:

GET Featured Products:
localhost:8000/api/products/featured/
[
    {
        "id": 1,
        "name": "Featured Product",
        ...
    }
]

Bulk Update Variants:
POST localhost:8000/api/products/{id}/bulk_update_variants/
[
    {
        "variants": [
            {
                "sku": "SKU1",
                "price_adjustment": "15.00",
                "attributes": [
                    {
                        "attribute_value": 1,
                        "required": true
                    }
                ]
            }
        ]
    }
]

Filter Products:
GET localhost:8000/api/products/?category=1&brand=2&min_price=100&max_price=1000&search=watch&featured=true&active=true
[
    {
        "id": 1,
        "name": "Filtered Product",
        ...
    }
]

Ví dụ sử dụng API để tạo sản phẩm với các thuộc tính và giá điều chỉnh:

POST /api/products/ (Form-data)
Form fields:
1. name: "Casio"
2. base_price: "1000.00"
3. description: "Đồng hồ Casio"
4. images[0]: [file1]
5. images[1]: [file2]
6. primary_image_index: 0
7. variants_data: [
    {
        "price_adjustment": "300.00",
        "stock_alert_threshold": 5,
        "is_active": true,
        "attributes": [
            {
                "attribute_value": 1,
                "required": true,
                "price_adjustment": 300000
            }
        ]
    },
    {
        "price_adjustment": "500.00",
        "stock_alert_threshold": 5,
        "is_active": true,
        "attributes": [
            {
                "attribute_value": 2,
                "required": true,
                "price_adjustment": 500000
            }
        ]
    }
]

// SKU sẽ được tự động tạo theo format: CASIO-VANG-1, CASIO-DEN-2
// Các giá trị price_adjustment sẽ được lưu vào bảng AttributeValuePriceAdjustment tương ứng với từng product và attribute_value.
