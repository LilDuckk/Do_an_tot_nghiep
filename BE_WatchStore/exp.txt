# API Orders

## 1. Orders API (/api/orders/orders/)
### GET /api/orders/orders/
- Lấy danh sách đơn hàng
- Query params:
  - customer: Lọc theo khách hàng
  - status: Lọc theo trạng thái
  - payment_method: Lọc theo phương thức thanh toán
  - search: Tìm kiếm theo order_number
  - ordering: Sắp xếp theo order_number hoặc created_at
- Permission: DjangoModelPermissions

### POST /api/orders/orders/
- Tạo đơn hàng mới
- Body:
```json
{
    "customer": "customer_id",
    "store": "store_id",
    "employee": "employee_id",
    "order_date": "order_date",
    "status": "status_value",
    "payment_method": "payment_method_value",
    "payment_status": "payment_status",
    "shipping_address": "shipping_address",
    "shipping_method": "shipping_method",
    "tracking_number": "tracking_number",
    "subtotal": "subtotal",
    "tax": "tax",
    "shipping_fee": "shipping_fee",
    "discount": "discount",
    "total_amount": "total_amount",
    "note": "note",
    "is_online_order": "is_online_order"
}
```
- Permission: DjangoModelPermissions

### GET /api/orders/orders/{id}/
- Lấy chi tiết một đơn hàng
- Permission: DjangoModelPermissions

### PUT /api/orders/orders/{id}/
- Cập nhật toàn bộ thông tin đơn hàng
- Body: Tương tự POST
- Permission: DjangoModelPermissions

### PATCH /api/orders/orders/{id}/
- Cập nhật một phần thông tin đơn hàng
- Body: Các trường cần cập nhật
- Permission: DjangoModelPermissions

### DELETE /api/orders/orders/{id}/
- Xóa đơn hàng
- Permission: DjangoModelPermissions

## 2. Order Details API (/api/orders/order-details/)
### GET /api/orders/order-details/
- Lấy danh sách chi tiết đơn hàng
- Query params:
  - order: Lọc theo đơn hàng
  - product: Lọc theo sản phẩm
  - variant: Lọc theo biến thể
  - ordering: Sắp xếp theo created_at
- Permission: IsAdminUser

### POST /api/orders/order-details/
- Tạo chi tiết đơn hàng mới
- Body:
```json
{
    "order": "order_id",
    "product_variant": "variant_id",
    "quantity": "quantity",
    "coupon_id": "coupon_id" // optional
}
```
- Giá sản phẩm được tính tự động:
  - unit_price = base_price + price_adjustment
  - discount = giá trị giảm từ coupon (nếu có)
  - final_price = (unit_price - discount) * quantity
- Validation:
  - Kiểm tra coupon có hợp lệ không (còn hạn, chưa vượt quá số lần sử dụng)
  - Kiểm tra giá trị đơn hàng tối thiểu nếu coupon yêu cầu
- Permission: IsAdminUser

### GET /api/orders/order-details/{id}/
- Lấy chi tiết một mục trong đơn hàng
- Response bao gồm:
  - Thông tin sản phẩm (product)
  - Thông tin biến thể (variant)
  - Thông tin coupon (nếu có)
  - Giá gốc (unit_price)
  - Giảm giá (discount)
  - Giá cuối cùng (final_price)
- Permission: IsAdminUser

### PUT /api/orders/order-details/{id}/
- Cập nhật toàn bộ thông tin chi tiết đơn hàng
- Body: Tương tự POST
- Permission: IsAdminUser

### PATCH /api/orders/order-details/{id}/
- Cập nhật một phần thông tin chi tiết đơn hàng
- Body: Các trường cần cập nhật
- Permission: IsAdminUser

### DELETE /api/orders/order-details/{id}/
- Xóa chi tiết đơn hàng
- Permission: IsAdminUser

## 3. Coupons API (/api/orders/coupons/)
### GET /api/orders/coupons/
- Lấy danh sách mã giảm giá
- Permission: IsAdminUser

### POST /api/orders/coupons/
- Tạo mã giảm giá mới
- Body:
```json
{
    "code": "code",
    "description": "description",
    "discount_type": "percentage|fixed",
    "discount_value": "discount_value",
    "minimum_order_amount": "minimum_order_amount",
    "start_date": "start_date",
    "expires_at": "expires_at",
    "usage_limit": "usage_limit",
    "is_active": "is_active"
}
```
- Validation:
  - Thời gian kết thúc phải sau thời gian bắt đầu
  - Giảm giá theo phần trăm không được vượt quá 100%
- Permission: IsAdminUser

### GET /api/orders/coupons/{id}/
- Lấy chi tiết một mã giảm giá
- Response bao gồm:
  - Thông tin cơ bản của coupon
  - Trạng thái hiệu lực (is_valid)
  - Số lần đã sử dụng (usage_count)
- Permission: IsAdminUser

### PUT /api/orders/coupons/{id}/
- Cập nhật toàn bộ thông tin mã giảm giá
- Body: Tương tự POST
- Permission: IsAdminUser

### PATCH /api/orders/coupons/{id}/
- Cập nhật một phần thông tin mã giảm giá
- Body: Các trường cần cập nhật
- Permission: IsAdminUser

### DELETE /api/orders/coupons/{id}/
- Xóa mã giảm giá
- Permission: IsAdminUser

{
    "first_name": "first_name",
